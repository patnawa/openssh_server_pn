# Code of conduct

This project is small and technical, and it depends on people sharing build results, bug
reports and fixes across many Windows versions. To keep that working:

- Be respectful and factual. Critique packages, configurations and ideas, not people.
- Assume good intent. Many contributors are testing on hardware or Windows versions the
  maintainers do not have.
- Keep reports and discussions on topic and reproducible: versions, hashes, exact commands and
  exact output.
- No harassment, discrimination, personal attacks or publishing of others' private
  information, in issues, pull requests or any other project space.
- Security-sensitive details go through the process in [SECURITY.md](SECURITY.md), not into
  public threads.

Maintainers may edit, hide or lock content and block accounts that violate these rules.
Concerns about conduct can be raised privately with the repository owner through GitHub.
